## Start with a clear first milestone

1. Describe the problem, expected behavior and relevant stack. Share only material you are authorized to share; omit passwords and production secrets.
2. Agree the scope, acceptance checks, required inputs and communication cadence before work starts.
3. Review the result with relevant test evidence, setup or handover notes, and any remaining limitations.

**Rate:** EUR 40/hour gross. An optional **EUR 200 gross diagnostic** covers one agreed issue, up to five work hours, and a written findings report within seven calendar days after the agreed inputs are received. Implementation and ongoing support are scoped separately.

For a custom need beyond these examples, I can first assess feasibility and propose a bounded scope. Availability, total price and delivery dates are agreed for each project.
